# ⚔️ 武侠词汇录 — ตำนานจอมยุทธ์อักษรจีน

เกมฝึกคำศัพท์ภาษาจีนแบบเล่นคนเดียว ธีมกำลังภายใน (Wuxia)
ออกแบบตามหลักความจำ **Active Recall + Spaced Repetition**
เพื่อให้จำคำศัพท์ได้จริง ไม่ใช่แค่ท่องผ่านตา

![Platform](https://img.shields.io/badge/Platform-CLI-lightgrey)

## ✨ จุดเด่น

- **พิมพ์คำแปลเอง** ไม่มีตัวเลือกให้เดา → ดึงความจำได้แรงกว่า
- **ตอบผิดแล้วคำเด้งกลับมา** ในอีก 2 คำ → เจอซ้ำตอนเกือบลืม
- **ระบบ 内力 (พลังภายใน)** เป็นค่าชีวิต 3 หน่วย เพิ่มความตั้งใจ
- **ระบบ 连击 (คอมโบ)** ตอบถูกติดกันครบ 5 ครั้งมีข้อความให้กำลังใจ
- **ตำแหน่งจอมยุทธ์ 5 ขั้น** จาก 无名小卒 ถึง 武林宗师
- **บันทึกคำที่ตอบผิด** ลงไฟล์อัตโนมัติ ไว้ทบทวนวันถัดไป
- **ยอมรับคำแปลได้หลายแบบ** ไม่ต้องพิมพ์ตรงเป๊ะก็ผ่าน
- **ไม่ต้องติดตั้ง library ใด ๆ** ใช้เฉพาะ standard library ของ Python

## 📚 คลังคำศัพท์

ชุดปัจจุบันมี **36 คำ** จัดกลุ่มตามตัวอักษรแม่ เพื่อให้จำเป็นก้อนได้ง่ายขึ้น

| ตระกูล | ความหมายแกน | คำในกลุ่ม |
|---|---|---|
| 压 | กด / อัด | 压迫 电压 高压 气压 压力 压缩 压制 镇压 |
| 至 | ถึง | 至今 至少 甚至 甚至于 以至 至于 自始至终 |
| 血 | เลือด | 血液 鲜血 血管 血汗 |
| 争 | แย่งชิง | 斗争 战争 争论 争取 竞争 力争 争夺 |
| 严 | เข้มงวด | 严格 严肃 严重 庄严 严禁 严厉 |
| เดี่ยว | — | 丝毫 竹子 伞 并且 |

### เพิ่มคำศัพท์ของตัวเอง

แก้ไขลิสต์ `VOCAB` ในไฟล์ `wuxia_vocab.py` ตามรูปแบบนี้:

```python
("汉字", "pīnyīn", ["ความหมาย1", "ความหมาย2"]),
```

ใส่ความหมายได้หลายแบบในลิสต์เดียว ระบบจะยอมรับทุกคำตอบในนั้น

## 🧠 หลักการเบื้องหลัง

| กลไก | อยู่ตรงไหนในเกม | ผลต่อความจำ |
|---|---|---|
| Active Recall | ให้พิมพ์คำแปลเอง | ดึงข้อมูลออกจากสมอง แข็งแรงกว่าการจำแบบรับรู้ |
| Spaced Repetition | คำที่ผิดเด้งกลับมาในอีก 2 คำ | ทบทวนตอนใกล้ลืม ทำให้ความจำคงทน |
| Desirable Difficulty | ระบบ 内力 ที่ลดลงเมื่อผิด | ความยากพอเหมาะทำให้เรียนรู้ลึกกว่า |
| Error Journal | บันทึกลง `wrong_words.txt` | เจาะจงทบทวนเฉพาะจุดอ่อน |
